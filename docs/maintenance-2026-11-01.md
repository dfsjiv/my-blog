# 2026-11-01 自主维护记录

本轮目标：在现有设计上完善阅读与写作流程，分批验证并部署。用户指定最多 5 小时或相关额度剩余 20% 时停止，以先到者为准。

## 第一轮：我的阅读

- 文章菜单增加“我的阅读”，游客也可以使用；个人中心有同名入口。
- 文章内支持“稍后读”、本地阅读进度、继续上次阅读。
- 阅读中心提供稍后读、历史、读完筛选，以及搜索、撤销移除、清空历史。
- JSON 备份导入／导出，导入校验格式及大小后合并，原记录不会被无效文件覆盖。
- 记录保存在浏览器，按游客／账号分别管理，最多 200 条，不存正文、密码、令牌或 Cookie，不新增数据库表。
- 阅读模块按需下载，不阻塞文章渲染；离开文章会清理事件、计时器与进度条。
- 阅读中心设置 noindex，避免将个人工具页纳入搜索索引。

验证：137 项自动化测试通过。Playwright 验证首页不加载阅读模块、收藏与续读、撤销、手机布局、路由清理。测试使用本地 fixture，没有写入线上文章或用户数据。

限制：记录不能自动跨设备同步；清除浏览器数据会删除记录，请使用导出备份。浏览器禁用存储时退化为本次页面的内存记录。

第一轮已提交并部署：`e188a87`。线上 HTML 已确认包含阅读入口及对应资源。

## 第二轮：文章导出与写作备份

- 文章页可按需导出 Markdown，首页不预下载导出工具。
- 写作页新增“备份与导出”菜单：Markdown、文章 JSON 备份、导入备份。
- 备份保留正文、分类、标签、封面链接、来源链接、题目信息和帖子外观；不携带账号凭据、服务器 ID、版本、作者权限或发布指令。
- JSON 导入只回填当前编辑器；不自动写入服务器。替换未保存内容时先提供确认与文件备份。
- 本站 Markdown 导出格式可重新导入，保留代码、居中 HTML 与元数据；未知 YAML 格式保留原文，不猜测或执行。
- 新本机草稿以账号 ID + 文章 ID 隔离。旧版未标记账号的本机草稿数据保留，不自动归属给任意账号。
- 修复“服务器已保存，但清理本机存储失败导致误报保存失败”。旧编辑器发现账号变化后拒绝继续保存。
- 手机写作工具栏及底部按钮改为清楚的两行，避免中文挤成竖排。

验证：141 项测试通过。Playwright 使用假账号、阻断所有网络写请求，验证导入、外观回填、本机键、手机按钮、模拟成功保存＋本机存储异常、账号变化拦截。未创建线上测试文章。

限制：备份中的图片保留链接，不打包图片文件。旧版无账号标记的浏览器草稿未自动迁移，避免串号。
